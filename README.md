# 图片翻译结构化训练数据工程

> 脱敏技术展示 / 项目案例说明
>
> 本仓库用于展示图片翻译版式理解的数据工程思路、流程设计和脱敏可视化材料。公开版本不包含内部源代码、训练数据、生产 Prompt、模型权重或服务配置。

## 项目简介

图片翻译的难点不只是把文字翻译出来，还要判断哪些 OCR 行需要合并为同一个翻译单元，并保持原图中的阅读顺序和渲染样式一致性。若逐行翻译，漫画气泡、广告艺术字、书页和多栏试卷中的译文容易割裂，版式也会被破坏。

个人职责是构建结构化训练数据体系，覆盖 OCR 行合并翻译判定、渲染样式一致性分析、HTML 合成数据、VLM 多阶段难例标注、规则校验、阅读顺序修复和数据入库。

## 个人职责

- 将 OCR 行合并翻译判定建模为行间关系预测，而不是只做目标检测；
- 设计 HTML + Playwright 合成数据生成系统，通过颜色注入反解元素像素级位置，保留 bbox / polygon 真值；
- 设计三阶段 VLM 标注流程：方向识别 → 容器 / 场景识别 → 翻译单元 / 阅读顺序；
- 通过结构校验、物理规则筛选和阅读顺序修复构建数据质量闭环。

## 关键结果

- HTML 合成数据系统可生产约 **50 万份**像素级标注样本；
- 覆盖聊天、漫画、菜单、书页、UI、表格等 **10 类场景**；
- 累计整理约 **2 万张** VLM 难例结构化标注图片；
- Stage 1 策略迭代 **87 版**，Stage 2 策略迭代 **90 版**；
- 重要场景文本行关系预测 F1：书本约 **95.0%**，广告 / 漫画约 **96.6%**；
- 合并判定准确率从 **0.878** 提升至 **0.955**，合并预测精确率从 **0.857** 提升至 **0.947**；
- 这些指标来自项目记录，公开版本不提供内部数据集和评测文件。

## 技术路线

```text
HTML 页面 / 真实难例图片
    ↓
HTML 颜色注入反解像素级标签 / OCR 文本与几何信息
    ↓
关系预测或 VLM 结构化标注
    ↓
Schema 校验 + 物理规则筛选
    ↓
阅读顺序修复与可视化
    ↓
训练数据入库与线上模型评测
```
