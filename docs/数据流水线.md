# 数据流水线

## 1. 合成数据分支

使用 HTML 页面控制文字、颜色、容器和布局，再通过 Playwright 并行渲染，保留元素的像素级位置。公开复现时应只使用自制页面和自定义文本。

## 2. VLM 标注分支

```text
图片方向识别
    ↓
容器 / 场景识别
    ↓
段组与阅读顺序
    ↓
结构化 JSON
```

项目材料记录的场景覆盖包括聊天、漫画、菜单、书页、UI 和表格等 10 类场景。

## 3. 质量控制

- Schema 校验：检查字段、类型和必填项；
- 物理规则筛选：检查坐标范围、polygon 合法性和几何关系；
- 阅读顺序修复：对不满足阅读顺序约束的结果做自动修复；
- 可视化复核：把 OCR 行、容器、段组和阅读顺序绘制回图片，定位问题样例。

## 4. 训练与评测闭环

```text
生成 / 标注
  → 校验
  → 筛选
  → 可视化
  → 修复
  → 入库
  → 模型训练与评测
  → 问题样例反馈
```

## 5. 公开复现边界

公开仓库可以提供一个小型自制数据集、几个结构化 JSON、可视化脚本和流程图；不包含真实业务样本、生产 Prompt 全文、内部标注数据、生产评测集或模型权重。
