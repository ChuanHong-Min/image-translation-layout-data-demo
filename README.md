# 图片翻译结构化训练数据工程

> 脱敏技术展示 / 项目案例说明
>
> 本仓库用于展示图片翻译版式理解的数据工程思路、流程设计和脱敏可视化材料。公开版本不包含内部源代码、训练数据、生产 Prompt、模型权重或服务配置。

## 项目简介

图片翻译的难点不只是把文字翻译出来，还要判断哪些 OCR 行属于同一个最小语义单元，并保持原图中的段组和阅读顺序。若逐行翻译，漫画气泡、广告艺术字、书页和多栏试卷中的译文容易割裂，版式也会被破坏。

个人职责是构建结构化训练数据体系，覆盖 OCR 行关系预测模型训练、HTML 合成数据、VLM 多阶段标注、规则校验、阅读顺序修复和数据入库。

## 个人职责

- 将段组判定建模为 OCR 行之间的关系预测，而不是只做目标检测；
- 设计 HTML + Playwright 合成数据生成系统，保留像素级位置标注；
- 设计三阶段 VLM 标注流程：方向识别 → 容器 / 场景识别 → 段组 / 阅读顺序；
- 通过结构校验、物理规则筛选和阅读顺序修复构建数据质量闭环。

## 关键结果

- 覆盖聊天、漫画、菜单、书页、UI、表格等 **10 类场景**；
- 累计结构化标注约 **1.2 万张图片**；
- Stage 1 策略迭代 **87 版**，Stage 2 策略迭代 **90 版**；
- 段组任务在书本场景 F1 约 **95.0%**，广告 / 漫画场景 F1 约 **96.6%**，相较线上规则方案分别提升约 **0.8pt / 1.8pt**；
- 这些指标来自项目记录，公开版本不提供内部数据集和评测文件。

## 技术路线

```text
输入图片 / HTML 页面
    ↓
OCR 文本与几何信息
    ↓
关系预测或 VLM 结构化标注
    ↓
Schema 校验 + 物理规则筛选
    ↓
阅读顺序修复与可视化
    ↓
训练数据入库与线上模型评测
```
